Credit Card Default Prediction

AAI 6610 - Applied Machine Learning

Neural Network Model | Model Tuning | GitHub Actions CI/CD

Project Overview

This project investigates credit card default prediction using a neural network model. The dataset contains 30,000 customer records and 23 original input features.

The objective is to identify customers who may default on their credit card payments.

Neural Network Model

The final model was trained using TensorFlow and Keras. It contains two hidden layers with 32 and 16 neurons.

Hyperparameter tuning was performed using eight configurations. Model selection was based on validation F1 score.

Model Performance

81.92% Accuracy
65.43% Precision
38.66% Recall
0.4860 F1 Score

These results are from the tuned model evaluated on the test dataset.

Deployment and CI/CD

The project uses GitHub for source code management. GitHub Actions performs basic validation and automatically publishes project files to Hugging Face Spaces.

Deployment Limitations

This Space uses Static HTML hosting. It presents the project and published model files but does not execute Python-based model predictions online.

A Gradio interface was also developed and launched in the local environment.
